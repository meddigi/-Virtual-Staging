# 아우름 배드민턴 센터 – 계약 전 시연용 홈페이지

공식 네이버 블로그(https://blog.naver.com/aurum_bdmt)에 공개된 내용을 바탕으로 만든 시연용 사이트입니다.
결과물은 이미지와 스크립트가 모두 들어 있는 HTML 파일 하나입니다. 웹폰트만 Google Fonts에서 불러오고, 연결이 없으면 시스템 폰트로 표시됩니다.

- 결과물: `dist/aurum-demo.html` (더블클릭으로 바로 열림)
- 다시 빌드: `python3 build.py`

## 구조
- `src/shell.html` – 공통 헤더, 푸터, 상담 모달, 모바일 퀵바
- `src/pages/*.html` – 메인 / 센터소개 / 프로그램 / 오시는 길
- `src/partials/*.html` – 약도 그래픽, 공식 블로그 섹션
- `src/styles.css`, `src/app.js` – 디자인 시스템, 해시 라우터, 인터랙션
- `assets/` – 블로그 배너에서 글자와 테두리를 지운 이미지

## 표기 원칙
요금, 코트 수, 시간표, 코치 경력처럼 블로그에서 확인되지 않은 정보는 넣지 않았습니다.
전화번호(010-0000-0000)와 상담 폼은 시연용이며, 실제로는 연결·전송되지 않습니다.
